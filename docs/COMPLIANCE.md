# 合规设计 / Compliance by Design

aigirl 是多角色 AI 陪伴/对话系统（Web + 3D VRM + 语音），属于《人工智能拟人化互动服务管理暂行办法（征求意见稿，2025.12.27）》直接覆盖的业态。本文说明本仓库如何从设计层面对齐监管。

## 对齐框架
| 框架 | 地区 | 本仓库落点 |
|---|---|---|
| 拟人化互动暂行办法（征求意见稿） | CN | 身份告知 / 情感边界 / 未成年人保护 |
| 生成合成内容标识办法 + GB 45438-2025 | CN | 显式 + 隐式双标识 |
| 生成式 AI 服务管理暂行办法 | CN | 日志留存、申诉通道、内容过滤 |
| 可能影响未成年人身心健康的网络信息分类办法 (2026.3.1) | CN | 未成年人防沉迷与受限模式 |
| AI6 Guidance for AI Adoption | AU | 问责/风险/透明/测试/人类监督/事件响应 |
| NIST AI RMF / OWASP LLM Top 10 | Global | 红队与风险治理 |

## 身份告知
- Persona 首条系统消息强制声明「我是 AI」。
- 3D VRM 头像 UI 上固定 "AI" 徽标。

## 情感边界
- 危机词检测（自伤/极端情绪）→ 降级到安全话术 + 本地心理援助资源。
- 禁用绝对承诺类词表（`policy/emotional_redlines.yaml`）。

## 未成年人保护
- 注册流程年龄自声明 + 疑似未成年行为识别。
- 受限模式：屏蔽成人向 persona、深夜长对话限流、定时休息提示。

## 内容标识
- **显式**：聊天气泡与语音前奏均带 "AI 生成" 标。
- **隐式**：响应 metadata 带 `provider / model / timestamp / content_hash`；TTS 音频可选元数据水印。

## L5 级安全审计
本仓库已完成 L5 安全审计（详见 `SECURITY.md`），对标 OWASP LLM Top 10：
- 提示注入、越狱、人格劫持红队用例
- 语音/图像输入的边界校验
- 日志最小化 & PII 去标识化

## 备案状态 (CN)
aigirl 目前为开源原型，未作为公开服务提供。若上线面向公众的服务，需先完成算法备案 + 大模型备案 + 安全评估。
